# Test Data: Do Not Modify

Files in this directory (and its subdirectories) are **conformance test data** for the
`env-source` cross-platform environment loader. They include real-world shell scripts and
batch files with their expected outputs across supported shells.

**Do not** refactor, reformat, rename, or rewrite any file here. Changes will break the
conformance tests.

If you need to update an input or expected output, do so intentionally as part of a test
change, never as a side effect of a codebase-wide refactor.
