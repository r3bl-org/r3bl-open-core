# r3bl-cmdr v0.0.27 Release Notes

**r3bl-cmdr** is a suite of fast, fully async TUI & CLI developer productivity tools built
on `r3bl_tui`:

- 😺 **`giti`**: Interactive Git CLI with visual branch selection and streamlined commit
  workflows.
- 🦜 **`edi`**: Terminal Markdown editor featuring syntax highlighting, gradient colors,
  emoji support, SSH-optimized diff-rendering, and a high-performance zero-copy gap
  buffer.
- 📜 **`env-source`**: Blazing fast cross-platform environment loader. Direct 100x faster
  Rust replacement for Fish [`bass`] (`bass.py`) on Unix and seamless `.bat` environment
  loader for PowerShell on Windows.

Install with:

```bash
cargo install r3bl-cmdr --force
```

## What's Changed in v0.0.27

### New Tool: `env-source`

`v0.0.27` introduces `env-source`, a blazing fast, cross-platform environment loader
designed to eliminate long-standing shell initialization and environment sourcing
bottlenecks across Unix and Windows:

- **Direct Replacement for Fish `bass` (`bass.py`) on Unix**: On Linux & macOS, Fish
  cannot natively parse POSIX/Bash environment variable exports. `env-source` is a drop-in
  replacement for [`bass`] (`bass.py`) to evaluate scripts like `~/.profile` directly into
  Fish.
    - **Over 100x Faster (~1.8 ms vs. ~221 ms)**: Eliminates Python runtime overhead,
      multiple sub-process spawns, and temporary disk files (`/tmp/`) used by `bass.py`.
      It spawns a single subshell, diffs environment states in memory, and pipes output
      directly to `source` (`env-source -i ~/.profile -o fish | source`).

- **First-Class `.bat` Environment Sourcing in PowerShell on Windows**: On Windows,
  PowerShell has notoriously lacked the ability to source legacy batch files (such as
  `vcvarsall.bat`, Python virtual environment `activate.bat`, or toolchain scripts).
  Developers historically had to rely on slow PowerShell wrapper scripts or regex hacks.
    - **Native Subshell Execution**: `env-source` evaluates `.bat` / `.cmd` scripts via a
      native `cmd.exe` subshell, handles Windows-specific case-insensitive key
      deduplication (preventing duplicate `PATH` and `Path` entries), and emits native
      PowerShell statements (`$env:KEY = 'value'`).
    - **Seamless Evaluation**: Can be evaluated directly in PowerShell with zero disk I/O:
        ```powershell
        env-source -i script.bat -o powershell | Invoke-Expression
        ```

- **Cross-Platform & Multi-Format**: Supports POSIX `sh`, Bash, Fish, PowerShell, and
  `cmd.exe`, with output formatters for Fish (`set -gx`), PowerShell (`$env:`), JSON, and
  Dotenv (`.env`).

### Tool Updates & Performance Boosts

- **`edi` (Terminal Markdown Editor)**:
    - Migrated to `r3bl_tui 0.8.0` with `Flat2DArray` offscreen rendering and new
      type-safe coordinate system (`VPPos`/`VPSize` vs `CPos`/`CSize`).
    - Optimized memory layout and initial allocations for `ZeroCopyGapBuffer`, improving
      editing performance on large Markdown files.
    - Benefited from 0ms zero-latency ESC handling and Kitty Keyboard Protocol support.
- **`giti` (Interactive Git CLI)**:
    - Migrated to `r3bl_tui 0.8.0` with enhanced keyboard handling (including modified
      navigation keys like `Shift+Home` and `Shift+End`).
    - Fixed terminal mode restorations to ensure clean exits on all platforms.
- **Windows ConPTY EOF Fix**:
    - Resolved process termination and EOF detection issues in Windows PTY integration.
- **Dependency Upgrades**:
    - Updated workspace dependency to `r3bl_tui = "0.8.0"`.
