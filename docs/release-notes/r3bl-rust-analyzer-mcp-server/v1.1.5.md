# r3bl-rust-analyzer-mcp-server v1.1.5 Release Notes

**r3bl-rust-analyzer-mcp-server** is a high-performance Model Context Protocol (MCP)
server for `rust-analyzer` designed specifically for pair-programming with AI coding
agents (Google Antigravity, Claude Code, Cursor, etc.).

## Why Synchronous? (Fit-for-Purpose Architecture)

While most Rust MCP implementations tend to wrap `stdio` inside an asynchronous runtime
like Tokio, an MCP server communicates over `stdio` in a **dedicated 1:1 parent-child
process relationship**. `stdin` and `stdout` cannot be polled via OS `epoll`/`kqueue`,
forcing async runtimes to delegate to blocking thread pools. So what is the point of
forcing the async paradigm here?

Instead of paying the cost of async runtime overhead, cancellation hazards, and complex
debugging when things go wrong, `r3bl-rust-analyzer-mcp-server` uses a lean, synchronous
**3-thread architecture** (`main` event loop, `stdout` reader, and background `stderr`
drainer) with pure Rust standard library threads:

- **Zero Async Runtime Overhead**: Instant cold-start (<2 ms) and minimal memory footprint
  with zero lock contention.
- **Deadlock-Free Pipe Draining**: Dedicated background `stderr` drainer prevents the
  classic 64 KiB OS kernel pipe buffer deadlocks when `rust-analyzer` emits large
  diagnostics.
- **Deterministic Teardown**: Clean EOF propagation on `stdio` disconnect with zero
  hanging processes or runaway 100% CPU loops on exit.
- **AST-Level Semantic Intelligence**: Provides lightning-fast code navigation, type
  hover, definition lookup, code actions, and compiler diagnostics directly to AI agents.

Read the architectural deep dive: [To Async or Not to Async: Building a Rust MCP Server
for rust-analyzer]

Install with:

```bash
cargo install r3bl-rust-analyzer-mcp-server --force
```

## What's Changed in v1.1.5

- **Framework Update**:
    - Updated workspace dependency to `r3bl_tui = "0.8.0"`.
    - Inherits core memory efficiencies and stability enhancements from `r3bl_tui 0.8.0`.
- **Pure Std-Thread Architecture**:
    - Delivers zero-runtime-overhead MCP integration for `rust-analyzer` using Rust
      standard library threads, providing sub-millisecond tool execution for AI coding
      agents without async runtime contention.
