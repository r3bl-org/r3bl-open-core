# r3bl-build-infra v0.0.6 Release Notes

**r3bl-build-infra** provides developer tools and utilities for Rust projects and
documentation automation:

- 📐 **`cargo-rustdoc-fmt`**: CLI tool that formats Markdown tables, converts inline links
  into sorted reference-style links, auto-links known technical terms, and normalizes code
  fence language tags in rustdoc comments (`///` and `//!`).

Install with:

```bash
cargo install r3bl-build-infra --force
```

## What's Changed in v0.0.6

### `cargo-rustdoc-fmt` CST Engine, Line-Range Formatting & Enhancements

- **Lossless CST Engine & Surgical Line-Range Formatting**:
    - Rebuilt `cargo-rustdoc-fmt` around a lossless two-level Concrete Syntax Tree
      (`SourceFileCst` / `DocBlockCst` / `DocNode`) with direct byte/slice scanners (zero
      regex dependencies), guaranteeing 100% byte-for-byte preservation of untouched code
      and comments.
    - Added `--lines <START-END>` and `--lines-force <START-END>` (supporting
      comma-separated 1-based inclusive ranges like `10-20,50-60`) for surgical range
      formatting of a single `.rs` file.
    - Added `--skip-folder-matches <PATTERN>` (defaults to `test_data`), `--dry-run`,
      `--skip-cargo-fmt`, `--terms-only`, and `--fences-only`.
    - Decoupled `#![rustfmt::skip]` from `cargo-rustdoc-fmt` so only `// rustdoc-fmt: skip`
      excludes files from rustdoc formatting, with automatic bypass when `--lines-force`
      is supplied.
- **Code Fence Normalization**:
    - Strips redundant `rust` language tags from opening code fences in rustdoc comments
      (` ```rust ` → ` ``` ` and ` ```rust,<attr> ` → ` ```<attr> `, such as
      ` ```rust,no_run ` → ` ```no_run `) since rustdoc treats unlabeled code fences as
      Rust by default.
- **Technical Term Auto-Linking**:
    - Automatically identifies and converts backticked technical terms into
      reference-style intra-doc links.
    - Added seed terms to the technical term dictionary, including `tokio`, `PTY`, and
      `pty`.
    - Added qualified path guards to prevent corrupting already-qualified symbol
      references.
- **Link Converter & Table Formatter Fixes**:
    - Fixed an issue where the term linker deleted multi-line plain reference definitions.
    - Fixed shortcut reference link clobbering.
    - Space-padded Markdown table separator rows (`| --- |`) and preserved code block /
      HTML comment boundaries inside doc blocks.
    - Removed `--include-lib-rs` and dropped redundant workspace scans for faster
      formatting runs.
- **Dependency & Test Suite Cleanup**:
    - Removed `pulldown-cmark`, `regex`, `once_cell`, `serde_json`, and
      `pretty_assertions` dependencies.
    - Consolidated all 23 end-to-end golden-file fixtures under `test_data/complete_file/`,
      reducing crate test suite execution time from ~3.6s to ~0.07s.
    - Updated workspace dependency to `r3bl_tui = "0.8.0"`.
